# Hellz

Building **HellzGate**, a multi-node wireless research platform based on ESP32-C5 hardware.

![C](https://img.shields.io/badge/C-00599C?style=flat&logo=c&logoColor=white)
![C++](https://img.shields.io/badge/C%2B%2B-00599C?style=flat&logo=cplusplus&logoColor=white)
![ESP-IDF](https://img.shields.io/badge/ESP--IDF-ESP32--C5-E7352C)

My work spans embedded C/C++, ESP-NOW and I2C communication, GNSS integration, and local SD logging.

**Current focus:** C5 FullGate — one master and nine scanners, with separate ESP-NOW and wired I2C bench validation completed.
